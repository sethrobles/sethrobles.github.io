Home Server

Setting up a home-server for hosting Tailscale Services including Actual Budgeting, my CMS, Fitness Trainer.

I recently have decided that there are some things that I want to host myself. This site for now is being hosted through github pages and being routed through my domain, sirobles.com.

Through the graces of labs and such, I have acquired a Jetson Orin Nano and a few Rasperry Pis (raspis), I think 2 3s, a 4, and a 5. I am wanting to set at least one of these up to be a home-server for hosting basic information.

The home server currently includes a Homepage dashboard a hosted CMS (using to write this now), Actual Budget, a small flashcards app that is potentially being replaced by a Gemini Notebook LLM workflow, a personal VaultWarden that I'm struggling to integrate well, a Calendar service, and a personal agent in progress.

In the future, this might take on more than just a Raspberry Pi 4B (especially if I get more into training models or running local LLMs) but for now, the Pi seems to be sufficient.
