# robots.txt for sirobles.com
#
# Policy, in one line: read it, summarise it, cite it — don't train on it.
#
# The split below follows that. Retrieval agents fetch a page to answer a
# question a human just asked and put a link back in the answer; that's a
# reader arriving sideways, and they're welcome. Bulk training crawlers take
# the same words to build a model and send nobody back; they aren't.
#
# This is a request, not a fence. Well-behaved crawlers honour it, scrapers
# ignore it, and a User-agent string can claim to be anything. Anything that
# genuinely must not be public should not be published here in the first place.
#
# Bot names drift — operators rename, split and retire them. When revisiting
# this, check the operators' own docs rather than trusting the list below.

# ── Ordinary search engines, and anything not named further down ─────────────
# Crawlers obey the single most specific group that matches them and ignore
# every other, so a bot with its own section below never reads this one.

# ── Pages kept out of results ────────────────────────────────────────────────
# Handled with <meta name="robots" content="noindex"> on the pages themselves
# (/qr/ and /404.html), deliberately NOT with Disallow lines here. Disallow
# blocks *crawling*, and a page that can't be crawled can't be read — so the
# noindex tag would never be seen, and the URL could still surface in results
# on the strength of inbound links alone. To hide a page, let it be fetched and
# let it say noindex. That is also why nothing unlisted is named in this file:
# a Disallow line is a public index of the things you'd rather people not find.
